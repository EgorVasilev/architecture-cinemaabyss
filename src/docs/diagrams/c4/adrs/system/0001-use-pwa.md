# 1. Use Progressive Web Application (PWA) as frontend basis

## Date
2026-05-21

## Status
Accepted

## Context
1. Требуется поддержка разных видов UI: веб, SmartTV, мобильные устройства
2. Небольшая команда full-stack разработчиков: есть сложность в поддержке множества разных UI-клинетов
3. Стоит выбор между:
    1. Веб-приложение и нативное приложение под каждую платформк
    2. React Native
    3. PWA + PWABuilder как "адаптер" для SmartTV

## Decision
Мы решили использовать PWA как основу и PWABuilder как инструмент портирования веб-приложения на другие платформы (Play Market, App Store, webOS, Tizen (Samsung) и т.д.)

## Consequences
- **Positive:** Мы сэкономим силы команды на создание и поддержку клиентов для разных платформ
- **Negative:** 
    - Проблематично использовать некоторые нативные особенности платформ
    - Сложности с адаптацией (стилизацией) приложения под все платформы 
- **Neutral:** Потребуется модернизация нынешнего веб-приложения до PWA
